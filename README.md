# Cat Sticker Sheet

把一张猫咪照片变成一张复古摄影拼贴贴纸版：同一只猫进入九种普通人类情境，再用一个轻微错位产生可爱和荒诞。

它保留猫咪可见的品种/类型、毛色、花纹、脸型、耳朵和眼睛特征，不推断猫咪性格。电话、塑料袋头套、棒球帽、浴巾、咖啡等只是尺度校准：物件保持日常、行为一眼能懂、每张只有一个不对劲的地方。

固定输出为 3:5 竖版、2 大 + 4 中 + 3 小主贴纸、6 枚微贴纸，以及统一单层白色模切描边。

## 安装

```bash
npx skills add https://github.com/hiyeshu/cat-sticker-sheet -g -a codex --skill cat-sticker-sheet -y
```

## 使用

附上一张清晰的单猫照片，然后调用：

```text
用 $cat-sticker-sheet 保留这只猫的外貌特征，让它使用普通人类道具做日常小事；每张只保留一个轻微错位。
```

## 设计原则

- 猫咪身份来自照片，不来自性格推断。
- 道具负责建立日常情境，猫咪替代人类执行动作。
- 一张贴纸只讲一个笑点；需要解释两句话就删减。
- 普通物件保持普通材质，不靠奇幻设定和复杂混搭制造效果。
- 写实猫脸、低保真摄影拼贴和单层白边保持统一；背景根据当页猫咪与道具配色决定，不设固定默认色。
