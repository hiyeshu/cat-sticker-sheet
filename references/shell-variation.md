# 外壳槽位：骨架固定，机制变化

发明先于排列。**先发牌，后找物件。**

所有九片先锁定同一可见骨架：**一张清晰写实猫脸居中，嵌在一个夸张大外壳的干净开口里；外壳遮住或替代身体。** `mechanism` 只描述外壳怎样承重、怎样变形、怎样制造笑点，不得把贴纸变成自由道具场景。

## 为什么不能物件先行

若从「可爱帽子清单」起手，外壳会滑向最省力的复制：九个不同道具，九张相同轮廓和同一张猫脸。正确起点是先决定外壳如何围住脸和耳朵、材料为何反常、表情为何属于这只猫，再选择具体物件。

坍缩的精确定义是：**从「写实脸嵌入夸张外壳」退化成「猫旁边摆道具」、九个自由场景，或九个同构洞口。**

成立的荒诞至少打破一项常识：猫脸顶替了物件的功能位置、特殊材质顶替了常规材质，或猫的视觉性格顶替了人类角色。失败的成图只是给猫脸贴一个无受力关系的装饰，因此既不可信也不好笑。

所以每片的生成顺序强制为：

```
外壳机制  →  脸部开口与耳朵/前爪如何承担它  →  哪个熟悉物件能提供外轮廓  →  哪种意外材质造成错位  →  哪个性格化表情收尾
```

## 九槽位：一条规则替代四条

不再依靠「尽量多变化」「更加荒诞」这类不可观测的软要求。先用一条机制规则阻止构造坍缩：

> **九片，九种机制，双射，不重复。**

| 机制 | 含义 | 猫做什么 |
|---|---|---|
| `becomes_part` | 猫头成为功能部件 | 脸、耳、胡须或眼睛承担按钮、表面、天线或读数结构 |
| `replaces_silhouette` | 猫头替换物件主体轮廓 | 物件形状由脸缘和耳尖共同完成 |
| `wraps` | 材料包裹头部 | 折痕、拉力与厚度必须顺着脸和耳朵 |
| `wears` | 猫真实穿戴物件 | 物件有开口、压痕、耳洞、绑带或平衡点 |
| `operates` | 头或前爪操作物件 | 只允许前爪局部进入，不退化成全身场景 |
| `spills_from` | 脸或毛发从材料中溢出 | 毛量与材料边缘发生可信挤压 |
| `peeks_through` | 透过特殊材料被看见 | 透明、半透明、网眼或反射会改变但不遮没身份 |
| `nests` | 猫头嵌在承托结构中 | **全页仅一个配额**，仍以脸为主 |
| `face_window` | 开窗本身成为主要视觉笑点 | **全页仅一个配额**；其他八片也有干净脸部开口，但笑点来自别的外壳关系 |

`nests` 与 `face_window` 是模型最容易复制的两条外壳关系，各限一片。剩下七片仍然要保持脸居中开口，同时在轮廓、受力和材料行为上真的想办法。

**尺度配额**：`hero` 2 / `medium` 4 / `small` 3。
**灵感领域**：九片至少覆盖 6 个 `domain`，从食物、饮品、浴室、运动、时装、包装、办公、家居、旅行、自然、工业、玩具中跨域取材。
**材质**：至少 4 个 `material_class`；同一具体材质不超过 2 片；同一主色不超过 3 片。
**表情**：至少 5 种 `expression`，但全部来自同一个 `visual_persona` 的表情语法。
**荒诞度**：至少 2 片 `high`，至少 5 片为 `medium` 或 `high`；其余低风险片负责让猫咪身份稳定可读。

## displaces：荒诞落点

每片必须回答一句话：

> **这张贴纸打破了哪一种正常位置、角色或材料预期？**

答不上来，或者答案只是「内部」「空腔」「里面」，说明这片只有装饰没有笑点——**作废，换下一个。**穿戴类允许由特殊材质顶替常规材质；功能类允许由猫脸、耳朵、胡须或前爪顶替原部件。

这一句同时干掉三件事：无笑点的贴装、模板复用，以及「视觉笑话」这个无法验收的玄学词。它把审美判断变成可陈述的结构检验。

同一页内，两片不得顶替同一个位置。

## 特殊材质：可信地不合理

使用四个彼此独立的字段，禁止把它们揉成一句“奇怪材质”：

- `material`：具体材质名称；
- `material_class`：食物、织物、纸、包装、透明、反射、硬质、有机或混合；
- `material_behavior`：它在画面上如何折、压、垂、裂、透、反光、起皱或回弹；
- `wearable_fit`：外壳的开口、边缘和支撑如何顺着头骨、耳尖、脸缘或前爪真实受力。

材质越荒诞，物理表现越要可信。透明材料要有折射与厚边，软材料要有压痕与重力，脆硬材料要有开口与支撑，反光材料不能变成无纹理的银色塑料。只改颜色不算材质变化。

具体物件与具体材质必须分别发明，再组合。用户举出的西瓜皮、浴巾、棒球、咖啡只是概念方向，不是必选清单，也不得成为每次运行的固定库存。

## 把基因与性格当燃料

`subject.generative_cue` 是一条硬要求：**这只猫的哪个特征驱动物件、材质或表情选择。**

- 成对但不对称的身份锚点 → 选择能把左右差异变成结构的物件；
- 长毛 → 选择会被毛发撑开、挤满或溢出的材料关系；
- 圆脸 → 选择与脸缘产生压合、环绕或读数关系的几何；
- 低能量呆憨感 → 让材质和身份错位承担笑点，表情保持慢半拍；
- 高能量机灵感 → 让眼神与前爪主动参与，但保持原眼型和面部比例。

至少三片的物件或材质必须从可见基因推出，至少六片的 `persona_fit` 必须从 `visual_persona` 推出。**换一只猫就不成立**。表情应有变化，但不能把猫轮流画成九种互不相干的人格。

### 几何征用表

给模型的原料是形状对应，不是物件清单。**给轴，不给值。**

| 猫贡献的几何 | 可被征用为 |
|---|---|
| 尖耳（三角） | 翼、峰、冠、开瓶器、折角、天线 |
| 爪垫（花瓣簇） | 花、按钮组、门吸、印章 |
| 长毛（绒面） | 填充物、除尘头、隔热层、溢出物 |
| 胡须（辐射线） | 天线、刻度、喷射线 |
| 瞳孔（缝／圆） | 表盘、镜头、锁孔、水位线 |

**永远不要给物件示例清单。**一旦写出「比如吸尘器、洗衣篮、面包机」，所有层次的模型都会照抄清单，多样性反而死得更快。清单是毒药。

## 装饰 = 主贴纸的因果余波

六枚装饰不是主题的同义词，是**九个荒诞穿戴发生过的证据**。它们应当表现碎屑、折痕、液滴、包装残片、脱落部件或其他由主贴纸动作造成的余波。

至少四枚必须声明 `residue_of`，指向不同的主贴纸编号。剩下零到两枚可以是短文字标签。通用的爪印／小鱼／毛线球／铃铛四件套一律拒收——它换页不换，正是跨成图重复的温床。

## 风险梯度

全冒险会崩，全稳会平。配额写死：

- 两片 `hero` 承担最强的外壳轮廓、材质对比和至少一项高荒诞关系；
- 七片里留两片稳的做视觉锚；
- 其余走中档。

## 跨成图去重：语义档位，不是词面黑名单

锚点库存固定在 Skill 的 `references/anchor-exclusions.json`；历史成图落在调用项目的 `output/cat-sticker-sheets/ledger.json`。`scripts/validate_plan.py --ledger` 自动合并两者。三条判据：

- `object` 完全同名 → 永久拒收；
- `displaces` 的荒诞落点重复 → 永久拒收；
- `(mechanism, domain)` 档位在最近三页内复用 → 拒收。

**不再维护手写的物件黑名单。**词面级排除挡不住语义重复——「沙拉甩干器」和「滤水篮」是同一个原型，「文件分格架」和「分格收纳盒」是同一个原型。手写清单还会随每张成图线性膨胀，最终污染上下文并与磁盘上的真实产物失去同步。

黄色锚点的具体库存只由 `anchor-exclusions.json` 承担排除，不再复述，也不把任何生成样例打进 Skill 包。

## freeform 逃生舱

`"freeform": true` 时放开机制双射与尺度配额，仅保留：≥5 种机制、`face_window` ≤1、`nests` ≤2、灵感领域 ≥6、材质类别 ≥4、表情 ≥5，以及中高荒诞度配额。

**`displaces` 永不豁免。**脚手架可以拆，检验不能拆。

只在单张精品、且使用高能力模型时开启；批量与跨模型场景一律走默认。
